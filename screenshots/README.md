# Screenshots

This folder is reserved for genuine screenshots captured from the running TaskFlow Android app.

Suggested files:

- `home.png` — main task list
- `task-editor.png` — create/edit task form
- `task-details.png` — task information and subtasks
- `filters.png` — search, priority and date views
- `dark-mode.png` — dark appearance

Please use screenshots from the actual app. Do not add mockups or generated images that could be mistaken for the running product. Once screenshots are added, embed them in the root README.
